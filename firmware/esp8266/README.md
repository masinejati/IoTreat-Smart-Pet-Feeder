# ESP8266 firmware recovery status

The original university presentation documents Wi-Fi, NTP and an embedded HTTP web server, but the complete original ESP8266 source is not included in this package.

Historical source link: https://gist.github.com/masinejati/910b18335b36653a8483f609a42ca6c1

**Security:** The historical Gist reportedly contains a hardcoded Wi-Fi credential. Do not copy it into this public repository without sanitizing the code, including reviewing Git history. Rotate the credential if it remains active.

This folder does **not** represent a recovered or tested ESP8266 firmware build.
