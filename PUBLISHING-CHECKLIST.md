# Before making the GitHub repository public

- [ ] Confirm both original project contributors consent to public release of their work and images.
- [ ] Inspect the two original PDFs for personal information, Wi-Fi names/passwords and private network details before publication.
- [ ] Decide whether to publish the PDFs in full; remove any confidential material first.
- [ ] Rotate any real Wi-Fi password exposed in the original Gist if still in use. A sanitized new repository does not erase the historical Gist.
- [ ] Do not add the original ESP8266 source until any credentials are stripped.
- [ ] Check photo permissions and visible personal information.
- [ ] Keep the original and the post-project maintenance sketch separate.
- [ ] Avoid claiming the maintenance copy has been compiled or hardware-tested.
- [ ] Publish and then add the repository URL to your CV.
